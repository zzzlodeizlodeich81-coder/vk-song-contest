# Конкурс треков для ВК

Репозиторий: https://github.com/zzzlodeizlodeich81-coder/vk-song-contest

Каркас мини-приложения: загрузка трека, согласие 85/5/10, текст, плеер, три шкалы, сумма баллов, правило «3 чужих оценки».

## Важно про Vercel

Vercel хорошо держит **статический фронт**. Загрузка mp3 + SQLite на серверлесс не живёт: нет постоянного диска. Для боевого конкурса бэкенд нужен Render / Railway / VPS, файлы — S3.

`vercel.json` отдаёт папку `frontend/`.

## Локальный запуск (полный цикл с файлами)

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --reload --port 8787
```

http://127.0.0.1:8787

1. Войти как `1001`, залить mp3, подтвердить текст, принять оферту.
2. Другие окна: `2002`, `3003`, `4004`.
3. Оценить 3 чужих трека после 45 сек прослушивания.
